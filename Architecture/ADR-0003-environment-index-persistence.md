# ADR-0003: Environment Indexを再生成可能な端末キャッシュとして永続化する

- 状態: 採用
- 日付: 2026-08-12
- 対象バージョン: 0.1.0
- 根拠仕様: `Vertex_AI_Master_Development_Prompt_Complete.md`

## 背景

Environment Explorerは起動のたびに全探索を繰り返してはならず、クラウドやプロバイダーが利用できない状態でも前回の観測結果を参照できる必要がある。一方、端末インデックスは利用者が作成した原本データではなく、決定論的スキャンから再生成できる派生データである。

## 決定

Environment Indexをスキーマバージョン付きJSON文書としてTauriのアプリ専用データ領域へ保存する。

- UIの`localStorage`を正本にしない。
- UIは起動後に前回キャッシュを読み、その後Coreへ再スキャンを要求する。
- Coreが新旧スナップショットを比較し、追加・更新・削除を構造化した`EnvironmentDelta`を生成する。
- 観測時刻とEvidenceの時刻だけが変わった場合は、端末資産の実質的変更として扱わない。
- 保存は一時ファイルへの書き込み、同期、旧版バックアップ、置換の順で行う。
- 置換失敗時は旧版を復元する。

## データの位置づけ

保存されたスナップショットは観測キャッシュであり、現在状態を保証するものではない。UIは最終観測時刻を表示し、再スキャン結果を受け取るまでは過去の観測として扱う。

## 採用理由

- 起動直後に前回結果を表示できる。
- 外部データベースが停止していても端末観測履歴を利用できる。
- 原子的置換により途中終了で壊れにくい。
- スキーマバージョンにより将来の移行を管理できる。
